## 🚀 Featured Projects

- **[MDM2–PMI Interface Analysis & Alanine Scanning](https://colab.research.google.com/drive/1xlllFkiCsvG_ZLAwtfd8yjXIsCcmMDAd)**  
  Structural bioinformatics project analyzing the MDM2–PMI peptide complex (PDB: 3LNZ). Performed structure preparation, relaxation, and protonation using PyRosetta. Calculated interface descriptors (dSASA, RSA, H-bonds, hydrophobic contacts) and estimated binding energy changes (ΔΔG) via alanine scanning. Results were validated against experimental literature data.  
  *Stack: Python, PyRosetta, PDBFixer, Jupyter Notebook.*

- **[OpenFF Ligand Parametrization Pipeline](https://github.com/Antyushova/AntyushovaAA_biocad_chemnext-trainee-test-case)**  
  Developed a Python pipeline for automated preparation of small molecules for molecular dynamics. The script reads ligands from an SDF file, preserves original coordinates, calculates partial charges (Gasteiger), and generates Gromacs-compatible topology (`topol.top`) and coordinate (`conf.gro`) files. Implemented batch processing with error isolation so that a single ligand failure does not interrupt the entire pipeline.  
  *Stack: Python, RDKit, OpenFF Toolkit, ParmEd, Gromacs.*

- **Bacterial Genome Assembly (ITMO Megaschool Project)**  
  Assembled and annotated a bacterial genome as part of the ITMO Megaschool in Applied Genomics. Worked with NGS pipelines to process raw reads and produce a complete genome assembly.  
  *Stack: Linux (bash), FastQC, Trimmomatic, SPAdes, QUAST, Prokka.*

- **CST3 Amyloidogenicity Assessment (Bachelor's Thesis)**  
  In silico study of the L68Q mutation in cystatin C (CST3), which causes hereditary cystatin C amyloid angiopathy. The analysis combined sequence-based amyloid prediction (PASTA 2.0, TANGO, WALTZ) with stability assessment of the monomer (3GAX) and dimer (1G96) using DUET, DynaMut2, mCSM, SDM, and FoldX.  
  *Stack: PyMOL, PyRosetta, FoldX, R, Python.*
